## CropSyst-EHM Executable and Source Code

The CropSyst-EHM executable used for all model simulations reported in this study is provided in the `CropSyst_executable/` directory. The corresponding source code, including the model developments implemented in this study, is available through the following SVN repository.

**Note:** CropSyst-EHM is identified as `CropSyst_4_sunburn` in the source-code documentation.

### SVN Repository Information

- **Repository URL:** `svn://nas2.bsyse.wsu.edu/CropSyst/trunk`
- **Source-code version:** `CropSyst_4`, including the sunburn model developments.
- **Local source directory:** `.../dev/CropSyst/source`

### Source Code Setup and Dependencies

To obtain and configure the CropSyst-EHM source code, check out the SVN repository using the URL provided above.

After downloading the source code, refer to the following documentation for instructions on configuring the development environment and installing the required dependency libraries:

`.../dev/CropSyst/source/CropSyst_source_code.html`

Follow the instructions in this document to configure the dependencies required to build the model from source.
